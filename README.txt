TRAIL 45K — VERSION IPHONE

1. Ouvrir Trail45K_iPhone.html dans Safari (ou l’héberger sur un service statique).
2. Une fois hébergé/ouvert via une URL, Safari > Partager > Sur l’écran d’accueil.
3. Les validations OK / LIMITE / ÉCHEC sont sauvegardées localement sur l’appareil.
4. Aucun compte n’est nécessaire.

IMPORTANT : un fichier HTML téléchargé directement peut être ouvert par iOS, mais l’expérience “app écran d’accueil” est plus fiable une fois le fichier publié sur une URL HTTPS.
